## How to Add Yourself

1. **Join the organization** -- [Submit an invitation request](https://github.com/Jaidevstudio/support/issues/new?template=invitation.yml)
2. **Fork** this repository
3. **Edit** `Data.json` and add your entry at the end:
   ```json
   {
     "name": "Your Name",
     "github": "YourUsername",
     "role": "Member",
     "joined": "2026"
   }
   ```
4. **Submit a PR** with the title `Add YourUsername`
